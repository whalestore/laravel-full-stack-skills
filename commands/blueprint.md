# /blueprint 命令

创建新项目蓝图、扫描现有项目或交互式修改蓝图。

## 用法

```
/blueprint [mode] [options]
```

## 模式

| 模式 | 说明 |
|------|------|
| `--new <描述>` | 从提示词创建新项目蓝图 |
| `--scan` | 扫描现有项目生成蓝图（默认） |
| `--edit` | 交互式修改现有蓝图 |

## 选项

- `--output=<path>` - 指定输出路径（默认 `blueprint.md`）
- `--focus=<module>` - 仅分析/修改指定模块

## 示例

### 从提示词创建新项目蓝图

```bash
# 描述项目需求，自动生成功能分解和开发计划
/blueprint --new "一个电商平台，支持多店铺、商品管理、订单处理、支付集成"
```

### 扫描现有项目

```bash
# 扫描项目结构，分析测试覆盖率，生成蓝图
/blueprint

# 或显式指定
/blueprint --scan
```

### 交互式修改

```bash
# 进入交互模式，可添加/修改/删除功能
/blueprint --edit
```

## 交互式修改命令

在 `--edit` 模式下支持：

| 命令 | 示例 |
|------|------|
| 添加功能 | `添加功能: 支付集成` |
| 更新进度 | `更新进度: 用户认证 -> 100%` |
| 添加待办 | `添加待办: 实现邮件通知` |
| 修改描述 | `修改描述: 这是一个电商平台` |
| 删除功能 | `删除功能: 废弃功能A` |
| 完成 | `完成` 或 `done` |

## 工作流程

```
/blueprint --new "描述"     /blueprint --scan       /blueprint --edit
        │                         │                       │
        ▼                         ▼                       ▼
   解析需求描述              扫描项目结构             读取现有蓝图
        │                         │                       │
        ▼                         ▼                       ▼
   生成功能分解              识别功能模块             显示当前状态
        │                         │                       │
        ▼                         ▼                       ▼
   规划开发阶段              分析覆盖率               接收修改指令
        │                         │                       │
        └─────────────┬───────────┘                       │
                      ▼                                   ▼
              生成 blueprint.md ◄─────────────── 应用修改并保存
```

## 输出

在项目根目录生成或更新 `blueprint.md` 文件。
