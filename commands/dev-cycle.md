# /dev-cycle 命令

运行完整开发循环：TDD 开发 → 代码审查 → 更新蓝图。

## 用法

```
/dev-cycle <功能描述>
```

## 选项

- `--max-cycles=<n>` - 最大审查循环次数（默认 3）
- `--skip-review` - 跳过代码审查
- `--skip-blueprint` - 跳过更新蓝图
- `--dry-run` - 预览流程不执行

## 执行流程

```
/dev-cycle "实现订单取消功能"
    │
    ├── 1. /tdd-dev
    │       编写测试 → 实现 → 重构
    │
    ├── 2. /code-review
    │       多模型审查 → 自动修复
    │       (循环直到通过或超限)
    │
    └── 3. /blueprint --update
            更新项目进度
```

## 示例

```bash
# 完整流程
/dev-cycle 实现产品搜索功能

# 跳过审查（快速开发）
/dev-cycle 实现简单 API --skip-review

# 自定义循环次数
/dev-cycle 实现支付集成 --max-cycles=5
```

## 循环状态

| 状态 | 含义 |
|-----|------|
| 🔵 开发中 | 正在 TDD 循环 |
| 🟡 审查中 | 正在代码审查 |
| 🔄 修复中 | 审查发现问题，修复中 |
| 🛑 需干预 | 超过最大循环或需人工决策 |
| ✅ 完成 | 全部通过 |
