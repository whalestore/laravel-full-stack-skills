# 代码审查工作流

使用多个 AI 模型并行审查代码，自动修复问题，循环直到通过或达到最大次数。

## 配置

```yaml
max_retries: 3              # 最大自动修复次数
auto_fix: true              # 是否自动修复
priority_threshold: medium  # 自动修复的最低问题级别
human_intervention_on:      # 需要人工干预的情况
  - security_critical
  - architecture_change
  - breaking_change
```

---

## 步骤 1: 收集变更文件

获取待审查的代码变更：
```bash
git diff --name-only HEAD~1
```

或指定范围：
```bash
git diff --name-only main..HEAD
```

---

## 步骤 2: 并行调用审查模型

同时调用多个模型进行审查：

### Gemini 审查
**关注点**: 架构设计、性能优化
```
请审查以下代码的架构设计和性能：
- 类设计是否合理
- 是否有 N+1 查询
- 是否有不必要的复杂度
```

### Codex 审查
**关注点**: 安全性、最佳实践
```
请审查以下代码的安全性：
- SQL 注入风险
- XSS 风险
- 权限验证
- 敏感数据处理
```

### 智谱审查
**关注点**: 代码风格、文档
```
请审查以下代码的规范性：
- 命名规范
- 注释完整性
- 代码可读性
```

---

## 步骤 3: 汇总问题

收集所有模型的反馈，按优先级分类：

| 优先级 | 描述 | 处理方式 |
|-------|------|---------|
| 🔴 Critical | 安全漏洞、数据丢失风险 | 人工干预 |
| 🟠 High | 性能问题、逻辑错误 | 自动修复 |
| 🟡 Medium | 代码规范、可读性 | 自动修复 |
| 🟢 Low | 建议、优化 | 可选修复 |

---

## 步骤 4: 判断处理路径

```
问题分类
    │
    ├── 无问题
    │   └── ✅ 审查通过
    │
    ├── 仅 Low 级别
    │   └── ⚠️ 审查通过（建议改进）
    │
    ├── Medium/High 级别
    │   └── 🔄 进入自动修复循环
    │
    └── Critical 级别
        └── 🛑 人工干预
```

---

## 步骤 5: 自动修复循环

**条件**: 存在 Medium 或 High 级别问题，且重试次数 < max_retries

### 5.1 生成修复方案
根据问题描述生成具体修复代码。

### 5.2 应用修复
修改相关文件。

### 5.3 运行测试
// turbo
```bash
php artisan test
```

### 5.4 重新审查
返回步骤 2，使用相关模型重新审查修改的文件。

### 5.5 循环计数
```
retry_count += 1
if retry_count >= max_retries:
    -> 步骤 6: 人工干预
else:
    -> 继续循环
```

---

## 步骤 6: 人工干预

**触发条件**:
- 超过最大重试次数
- 发现 Critical 级别问题
- 需要架构变更
- 涉及破坏性变更

### 生成问题报告

```markdown
# 代码审查报告

## 审查状态: 需要人工干预 🛑

## 自动修复尝试: 3/3

## 未解决问题

### [问题 1]: SQL 注入风险
- **文件**: app/Http/Controllers/ProductController.php
- **行号**: 45
- **严重性**: High
- **描述**: 直接拼接用户输入到 SQL 查询
- **建议修复**: 使用参数化查询

### [问题 2]: 缺少权限检查
- **文件**: app/Http/Controllers/OrderController.php
...

## 需要人工决策
1. 问题 1 的修复可能影响现有功能
2. 问题 2 需要确认业务规则
```

---

## 步骤 7: 审查通过

**条件**: 所有 Medium 及以上问题已解决

### 7.1 提交修复
// turbo
```bash
git add .
git commit -m "fix: 代码审查修复"
```

### 7.2 生成审查报告

```markdown
# 代码审查报告

## 审查状态: 通过 ✅

## 审查统计
- 审查模型: 3
- 发现问题: 5
- 自动修复: 4
- 人工忽略: 1

## 修复记录
1. 修复 N+1 查询 (ProductController.php)
2. 添加输入验证 (StoreProductRequest.php)
...
```

---

## 产出

- ✅ 审查报告：代码质量评估
- ✅ 修复记录：自动修复的变更
- ❓ 人工干预请求：需要人工决策的问题（如有）
